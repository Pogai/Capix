# Capix - 固定框连续截图（托盘后台 · 长图预览 · 可设置）

Capix 取景框截图工具：**启动后在系统托盘后台常驻**（不弹窗），点托盘图标开始
框选；框选后屏幕上常驻一个**取景框**（蓝色 #3388FF 边框 + 白色开口箭头手柄，
内部透明，框内桌面可正常点击，上边框外侧贴**尺寸标签**实时显示宽高），
右下角悬浮**白底工具栏**（浅灰描边圆角条：六点把手 + 计数 + 深色图标按钮
截图 / 复制 / 移动 / 设置 / ✕，hover/按下浅蓝垫色、图标保持深色不透明，
可拖把手任意移动、双击复位）。
「移动」按钮可切换移动模式：**开启后鼠标移到框选区域内任意位置即可拖动整框平移**
（框内覆盖 6% 极淡蓝调，屏幕内容依然清晰可见；鼠标不穿透；中央显示移动徽标；
再次点击关闭后框内点击恢复穿透）。
每点一次「截图」截下当前框内画面；框侧**长图预览窗**实时显示已拼接长图
（长图越长缩得越小，并自动滚到最新一张）；点「复制」把本次所有截图**纵向拼成长图**
复制到剪贴板（可重复复制），**下一次截图时才开启新一轮拼接**；点「✕」退出框选、回到后台托盘。

Windows 纯 Python 标准库实现（Python 3.8+），**无任何第三方依赖**。

## 运行

**分享试用（推荐，单文件 exe，无黑框）：**

直接双击 `dist\Capix.exe`，或发给别人。运行后在托盘出现图标（无窗口、无控制台黑框）。
无需安装 Python。

**源码运行：**

```bat
run.bat
```
或
```
python app.py
python app.py D:\我的题库        # 指定输出目录
```

启动后**不弹窗**，到屏幕右下角任务栏**通知区域（托盘）**找图标（程序图标取自 `assets\icon.ico`）。

## 使用流程

1. 启动 → 后台运行，托盘出现图标（首次会弹一个气泡提示）。
2. **左键单击托盘图标** → 开始框选；拖动鼠标选出要连续截图的区域，松开确认。
   （也可右键托盘 → “开始框选”，或按 `Ctrl+Shift+R`。）
3. 出现常驻取景框 + 右下角工具条；**首次截图后**才出现框侧长图预览窗：
    - **边框可拖拽**：按住任意一条边或箭头手柄（4 角 + 每边中点，中心压在边线上）拖动，
      即可实时调整截图区域（最小 80×60，不会拖出屏幕）；
      松手后新区域立即生效，已截图片保留。截图瞬间手柄自动隐藏，不会截进图里。
      拖拽中上边框外侧的尺寸标签实时显示宽高变化。
    - **🤕移动模式**：点工具条「移动」按钮（四向箭头）开启，**鼠标移到框选区域内
      任意位置即可拖动整框平移**（尺寸不变）——无需点到边框上；
      框内覆盖 6% 极淡蓝调（看得见屏幕内容）+ 中央移动徽标 + 十字光标，鼠标不穿透；
      再次点击关闭，框内点击恢复穿透。截图时临时隐藏，不会影响画面。
   - **工具条可移动**：按住左侧六点把手拖动，可把工具条放到任意位置（本次会话内保持）；
     双击把手复位到取景框右下角默认锚点；若被拖进取景区，截图时会自动隐藏。
   - **📷截图**：截取当前框内画面并入拼接序列；首次截图后预览窗才弹出，随截图刷新。
     单次会话最多 N 张（默认 20，可在设置中改，范围 1~20）。
   - 预览窗操作：每次新截图后**自动滚到长图最底部**（最新一张始终可见）；
     图片比视口短时下方保持卡片底色（不会再出现拉伸条纹）。
     **鼠标滚轮**上下滚动、**Ctrl+滚轮**以光标为中心放大/缩小、
     **左键拖拽**平移、**双击**恢复按宽度适配；标题栏还有 **[＋][－][⟲]** 按钮。
   - 在框内正常点击桌面/应用（如点“下一题”），再点 **📷截图**，如此循环。
    - **⧉复制**：把本会话所有截图**纵向拼成长图**复制到剪贴板；
      **复制后不立即清零**，在点「截图」之前可反复复制（避免复制失败）；
      **下一次点「截图」才从 0 开始新一轮拼接**，并自动解除「已达上限」的禁用。
     还没截图就点复制时，工具条上方会弹完整提示（不截断）。
   - **⚙设置**：弹参数设置对话框（单次最大截图张数，默认 20、范围 1~20，
     保存即时生效并持久化到 `settings.json`）。
   - **✕**：退出框选，回到后台托盘（程序仍在运行）。
4. 单张截图与拼接长图都会保存到输出目录（跨会话连续编号，不覆盖）。

## 托盘 / 快捷键

| 操作 | 作用 |
| --- | --- |
| **托盘左键** | 开始框选 |
| **托盘右键** | 菜单：开始框选 / 打开截图目录 / 设置… / 打开日志目录 / 退出程序 |
| `Ctrl + Shift + R` | 开始 / 重新框选（开启新会话） |
| `Ctrl + Shift + S` | 截取当前取景框 |
| 工具条 `✕` | 退出框选（不退出程序） |

> 退出整个程序：右键托盘 → “退出程序”。

## 输出

- 单张：`输出目录/题N.png`（跨会话连续编号，不覆盖）
- 长图：`输出目录/题长图_HHMMSS.png`（点「复制」时同时生成）
- 剪贴板：同时写入 `CF_DIB` 与 `PNG` 两种格式，微信 / Word / 画图 / 浏览器均可直接粘贴

## 日志（问题记录 / 迭代）

- 日志文件位置：**exe 同目录的 `logs\`**（如 `dist\logs\capix_YYYYMMDD.log`）；
  若 exe 所在目录不可写，会自动回退到 `%LOCALAPPDATA%\capix\logs`。
- 记录内容：启动信息、托盘/热键状态、每次截图与复制、设置变更、异常堆栈
  （未捕获异常自动写入）。
- **右键托盘 → “打开日志目录”** 可直接定位日志文件，便于反馈问题。

## 设置

- 存储：exe/项目同目录 `settings.json`（不可写回退 `%LOCALAPPDATA%\capix\`）。
- 当前可配项：`max_shots` 单次最大截图张数（默认 20，范围 1~20）。
- 入口：工具条 **⚙设置** 或 托盘右键 → **设置…**；保存后立即生效并持久化。

## 重新打包 exe

```powershell
powershell -ExecutionPolicy Bypass -File build\build_exe.ps1
```
- `build\make_icon.py`：把 `assets\source_icon.png（拼图图标，用户提供的版本）` 转为多尺寸 `assets\icon.ico`
- `build\build_exe.ps1`：PyInstaller 单文件、`--noconsole`（无黑框）、内嵌图标，
  产物 `dist\Capix.exe`
- 图标替换：换掉 `assets\source_icon.png（拼图图标，用户提供的版本）` 后重新执行上面的脚本即可

## 技术要点

- **托盘后台**：`ctypes` 调 `Shell_NotifyIconW`，独立线程消息循环，
  右键 `TrackPopupMenu` 菜单，`NIF_INFO` 气泡通知。见 `tray.py`。
- **取景框（4 边条 + 8 箭头手柄）**：边条是纯色小窗口（蓝色 #3388FF、4px 粗，
  与框选拖拽线同色同粗）；手柄为**白色开口箭头**（`assets\ui\arrow_*.png`，
  4 角双箭头、每边中点单箭头、朝向随拖拽方向，**中心压在边框线上**）。
  素材按显示尺寸直接渲染 + **色键二值化**（白/色键两态，无灰阶混色，
  根除色键窗口的"断续黑边"）。
  创建时全部先隐藏、布局完一次性显示（无闪烁），手柄延后约 140ms 呈现；
  拖拽热路径已优化（geometry 去重、无同步刷新/改样式、预览不重渲染），
  全部原生可点击、按住即拖拽调整区域；截图瞬间隐藏手柄保证画面干净；
  框内没有任何窗口覆盖，桌面点击天然穿透。见 `frame.py`。
- **尺寸标签**：贴上边框正上方（贴屏顶时翻入框内），深底 #222222 圆角白字，
  拖拽调整/平移时实时同步宽高。见 `frame.py`。
- **浅色工具栏**：单 Canvas 自绘，白底不透明 + 浅灰描边；
  图标为深灰线性 PNG（#3A414A，不透明）；hover/按下浅蓝垫色 #E9F1FD/#D6E3FB，
  图标保持深色；移动模式开启时按钮持续高亮 #DBE8FC。见 `frame.py`。
- **长图预览**：`preview.py`；内容 = 会话长图按宽适配，后台线程生成 RGB 快照，
  主线程按视口逐行采样后 `PhotoImage` 贴图（只填有源图的行，剩余区域用卡片底色，
  避免“末行钳制”导致的拉伸条纹），每次刷新自动滚到底部。
- **复制延迟回滚**：`controller.copy_long_image()` 成功后不清空缓冲（可多次复制），
  置 `_pending_reset`，下一次截图时才重置计数；长图/单张文件编号继续递增不覆盖。
- **截取不含自身 UI**：边框画在区域外侧 3px、工具条/预览在框外；
  截图用 `SRCCOPY | CAPTUREBLT`。
- **长图拼接**：同宽图像逐行纵向拼接；若会话中调整过取景框导致宽度不同，
  按**最大宽度**拼接、左对齐原样拷贝，余下区域填浅灰底（`stitch.py`）。
- **剪贴板**：手写 24bpp 自底向上 DIB + PNG 注册格式（`clipboard.py`）。
- **DPI 感知**：启动即 `SetProcessDpiAwareness(2)`，框选坐标与截图像素一致。

    stitch.py       纵向拼接长图
    thumb.py        等比缩略（最近邻）
    preview.py      长图预览窗（懒显示、缩放/滚轮/拖拽）

## 说明与限制

- **单次会话上限默认 20 张**（可设 1~20）：到上限后「截图」按钮置灰。点「复制」后
  继续截可重新拼接，或 `Ctrl+Shift+R` 重新框选。
- **点「复制」不立即清零**：可连续多次复制（防一次复制失效）；**下一次截图时**才从 0
  开始新一轮拼接，单张文件编号始终继续递增不覆盖。
- 预览窗**首次截图后**才出现（未截图不占屏）；框占满屏宽时尝试左侧，再不行自动隐藏。
- 若托盘创建失败（少见），自动回退为**控制面板窗口**模式，功能一致。
- 当前覆盖**主显示器**；多显示器扩展屏切到主屏内框选。
- 取景框是屏幕坐标固定区域，按 `Ctrl+Shift+R` 重新框选；框选中可随时拖拽边条/箭头手柄微调。
- 拖拽调整后如果与已截图片宽度不同：长图按**最大宽度**拼接，每张图左对齐完整保留，
  宽度不足处填浅灰底（不会再出现“旧图被裁成一条”）。调整时会弹提示说明。
- 框紧贴屏幕边缘时，该边的拖拽条位于屏幕外、无法再向外拖动（向内可用相邻边）。
- 工具条默认在框右下角外侧；若框太靠屏幕底部，会自动移到框上方（避开截取）。
- 若某全局热键被其他程序占用，会提示改用托盘。
